# 3.11.0 · Clasificación canónica

- Un único resolver selecciona la clasificación LLM positiva, vigente y con evidencia literal específica; valida contexto y exclusiones. Los resultados débiles, inválidos, obsoletos y las abstenciones usan el determinista completo, sin mezclar IDs. Una exclusión editorial exige un pasaje público validado y una exclusión de las reglas actuales; no elimina el determinista guardado.
- El catálogo operativo incorpora 22 entradas locales «Otros», una por bloque, con IDs estables. Los dos bloques del prefijo 13 conservan IDs diferentes. El maestro de Drive permanece de solo lectura; no se publican categorías emergentes automáticas.
- Se retiran el modo de categorización y la dependencia trimestral del envío. La sincronización diaria del maestro es auxiliar; la traducción reutiliza nombres ya válidos y no reinicia un trabajo terminado sin cambios.
- La clasificación reutiliza resultados deterministas suficientes; el contenido, las reglas o el modelo invalidan ese resultado. El mantenimiento también reutiliza asignaciones estables. El coordinador prioriza traducción antes del correo y reserva un turno a mantenimiento/recuperación tras tres lotes auxiliares, conservando prioridad diaria y barreras de publicación.
- La migración canónica usa staging, lotes reanudables y validación de todo el corpus. Su marcador solo se confirma tras publicar los tres snapshots. La generación anterior se conserva para recuperación.
- Los lotes LLM de al menos 25 resultados sin positivos ni fuentes se señalan para revisión editorial. El intercambio sigue siendo JSON estricto v2; las nuevas instrucciones exigen investigar el editor público y evaluar bloque antes de suboperativa.

La evidencia, el inventario exacto de archivos, las pruebas y el estado real de publicación se registran en `canonical-3.11.0-validation.json`. Las medidas locales son observaciones del emulador; las de Apps Script no incluyen transporte del navegador. No acreditan un SLA ni calidad editorial de todo el corpus. Los resultados LLM de una revisión taxonómica anterior se conservan, pero requieren una nueva exportación/importación para volver a considerarse vigentes.
